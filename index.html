07 / Questions

Lurker Drops questions.

Still curious?Open an issue on GitHub

?

Is Lurker Drops really free?

Yes. Lurker Drops is open source. There is no account, no subscription, no ads and no paid tier.

Does Lurker Drops need the browser open?

Yes. The tab must stay open for Twitch to count the watch time. You can mute it, move it to the background, or send it to another window.

Will Lurker Drops keep changing channels?

Only the tab it manages. With Pursue on, it moves to a matching live with more viewers. Turn Pursue off to follow your favorites in the order you set.

Does Lurker Drops collect my data?

Your settings stay in browser storage. The extension only asks Twitch for the public list of live streams. Nothing else leaves the browser.

Does Lurker Drops guarantee drops?

No. It keeps a matching live open, but drops and rewards follow Twitch and campaign rules. Never use it to break those rules.

Can I run more than one tab?

Yes. Each tab has its own preset, mute state and Pursue setting. Add as many lurkers as you need.

Which browsers run Lurker Drops?

Chrome, Edge, Opera, Brave and other Chromium-based browsers on desktop. Firefox is not supported.
