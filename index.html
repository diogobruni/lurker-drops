What the extension does while you are away. Four jobs, every minute.

Picks a Twitch live for you

A preset holds a category, a title filter, favorites and a blacklist. Favorites go first.

Mutes the browser tab only

The tab plays without sound, so calls, music and games keep the speakers.

MutedMute the browser tab itself, not just the Twitch player.
PursueFollow the most-watched live matching this preset. Off keeps the current live while it remains valid.

Reconnects a dropped Twitch chat

When chat falls, it reconnects. If that fails, it reloads the page, once every 5 minutes at most.

Is it free?

Yes. The code is open on GitHub. No account, no subscription, no ads.

Does the browser have to stay open?

Yes. Twitch only counts watch time in an open tab. You can mute it, minimise the window or turn off the screen.

Does it guarantee drops?

No. It keeps the tab on a live that fits your rules. Drops follow the campaign rules set by Twitch and the game.

Does it collect my data?

No. Settings stay in your browser. It only asks Twitch for the public list of live streams.

Can I install it without the store?

Yes. Download the ZIP, open the extensions page, turn on Developer mode and drop the ZIP on it. Download the ZIP
