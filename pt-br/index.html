O que ele faz

Ajudante pequeno. Alívio grande.

É como pedir a um amigo para deixar a TV no canal certo. Só que esse amigo nunca se entedia.

  • Escolha o programa

    Selecione uma categoria, como um jogo ou Just Chatting. Adicione uma palavra que o título precisa ter, ou palavras que você nunca quer ver.

  • Uma predefinição por aba

    Lives tranquilas em uma aba, seu jogo favorito em outra. Cada aba guarda suas próprias regras, favoritos e lista de bloqueio.

  • Encontra uma live para você

    A cada minuto ele olha de novo. Se uma live maior combina com suas regras, a aba vai para lá. Desligue Perseguir para ficar nos favoritos.

  • Assistindo em silêncio

    Deixe a aba muda enquanto ela assiste. Seus alto-falantes ficam livres para chamadas, música ou o vídeo que você está vendo de verdade.

  • Resgate do chat

    Se o chat da Twitch cair, a extensão reconecta. Se não funcionar, recarrega a página, no máximo uma vez a cada cinco minutos.

  • Baús de bônus

    Quando um baú de bônus aparece na página, ela clica para você. Não precisa mais lembrar de olhar.

Como funciona

Três passos. Depois esqueça.

Você define as regras uma vez. A extensão faz a parte chata o dia inteiro.

  1. 01

    Diga o que assistir

    Abra o popup, escolha uma categoria e adicione um filtro se quiser. Salve como predefinição para reusar depois.

  2. 02

    Aperte Ligar

    A aba abre uma live compatível com suas regras e fica nela. O ícone mostra quantos lurkers estão ativos.

  3. 03

    Vá viver sua vida

    Trabalhe, estude ou jogue. A cada minuto ele confere de novo e mantém a live certa tocando até você desligar.

Você pode rodar várias abas ao mesmo tempo, cada uma com uma predefinição diferente.

Instalar

Adicione ao seu navegador em cerca de um minuto

O Lurker Drops agora está na Chrome Web Store. Instale com um clique ou use a versão do GitHub se preferir uma instalação manual.

Adicionar ao Chrome

Funciona no Chrome, Edge, Opera e Brave para desktop. O link abre a página oficial da Chrome Web Store.

  1. 1

    Abra a página da loja

    O botão acima abre a página oficial do Lurker Drops na Chrome Web Store.

  2. 2

    Clique em Adicionar ao Chrome

    Confirme as permissões. A extensão precisa de acesso às páginas da Twitch para manter a aba assistindo e reconectar o chat.

  3. 3

    Fixe e aperte Ligar

    Fixe o Lurker Drops na barra de ferramentas, abra o popup, adicione seu primeiro lurker e aperte Ligar.

Instalação manual pelo GitHub

Prefere uma instalação manual? Use o ZIP do release oficial e o Modo desenvolvedor. Mantenha o arquivo ZIP como está.

Baixar o release mais recente
  1. 1

    Baixe o ZIP

    O download sempre entrega o release mais novo do GitHub.

  2. 2

    Abra a página de extensões e ligue o Modo desenvolvedor

    Use chrome://extensions no Chrome e no Brave, edge://extensions no Edge ou opera://extensions no Opera. O interruptor fica no canto superior direito.

  3. 3

    Arraste o ZIP para a página

    Solte o ZIP em qualquer lugar da página de extensões e confirme. Se não funcionar, descompacte e use Carregar sem compactação com a pasta.

  4. 4

    Fixe e aperte Ligar

    Fixe o Lurker Drops, abra o popup e aperte Ligar.

Dúvidas

Bom saber

É mesmo de graça?

Sim. O Lurker Drops é código aberto. Não tem conta, assinatura, anúncio nem nada para desbloquear.

Preciso deixar o navegador aberto?

Sim. A aba precisa ficar aberta para a Twitch contar o tempo assistido. Você pode deixá-la muda, mandar para o fundo ou mover para outra janela.

Ele vai ficar trocando de canal?

Só a aba que ele gerencia. Com Perseguir ligado, ele vai para uma live compatível com mais espectadores. Desligue para seguir seus favoritos na ordem que você definiu.

Ele coleta meus dados?

Sem analytics, sem rastreamento e sem servidor. Suas configurações ficam no armazenamento do navegador, no seu computador. Ele só pede à Twitch a lista pública de lives.

Ele garante drops ou recompensas?

Não. Ele mantém a aba assistindo a uma live compatível com suas regras, mas drops e recompensas seguem as regras da Twitch e das campanhas. Nunca use para quebrar essas regras.

Quais navegadores funcionam?

Chrome, Edge, Opera, Brave e outros navegadores baseados em Chromium no desktop. O Firefox não é suportado.

Deixe suas abas esperando por você.

Instale uma vez. Escolha o programa. Aperte Ligar. É só isso.
